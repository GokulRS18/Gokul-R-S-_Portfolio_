# Gokul R S — Portfolio

A responsive single-page portfolio for Gokul R S, an AI/ML Developer & Data Analyst.

## Design direction
Inspired by the illustration-based portfolio concept referenced by the user:
- strong editorial typography
- illustrated/data-driven hero
- rounded project cards
- playful accent colors
- simple navigation
- responsive single-page layout

The implementation is an original build rather than a direct copy of the template.

## Files
- `index.html` — page content and structure
- `style.css` — responsive design system and illustrations
- `script.js` — mobile menu and reveal animations

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.
